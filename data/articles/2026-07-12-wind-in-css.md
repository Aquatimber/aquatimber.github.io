# 用 CSS 写一阵穿过松林的风

动效不只是物体从甲处移动到乙处。它也可以像一阵风：不直接出现，只借云气、枝叶与光线留下痕迹。

## 从留白开始

东方画面里的“空”并非没有内容。对网页而言，留白是节奏，也是性能预算。先决定什么不动，再让少数元素缓慢呼吸。

> 好的环境动效应当能被感知，却不争夺阅读的注意力。

我们可以用三个伪元素分别承载云、光和颗粒。它们共享同一块画布，但拥有不同的速度。

```css
.mist::before {
  background: radial-gradient(circle at 30% 40%, var(--mist), transparent 58%);
  filter: blur(32px);
  animation: drift 18s ease-in-out infinite alternate;
}
```

## 让颜色彼此渗透

不要直接把霓虹色放到水墨背景上。先降低饱和度，再利用混合模式让边缘互相渗透，炫彩就会像矿物颜料，而不是广告灯牌。

### 一份克制的参数表

| 层级 | 透明度 | 建议速度 |
| --- | --- | --- |
| 水墨底层 | 0.18–0.28 | 20–32 秒 |
| 矿物色光 | 0.08–0.16 | 14–24 秒 |
| 细流光线 | 0.16–0.24 | 8–16 秒 |

## 尊重系统偏好

当系统开启“减少动态效果”时，停下无限动画，只保留静态渐变。美感不应以眩晕和耗电为代价。

- 使用 `prefers-reduced-motion`
- 移动端减少粒子数量
- 页面隐藏时暂停 Canvas

最终，我们并没有真的画出风；我们只是给变化留出了一条路径。
